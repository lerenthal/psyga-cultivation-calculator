*INDEX — Calculation & Document Logic

Index section printed below the signatures for operator reference: how each form field is used and how every document section is calculated.

{% if kind == "cultivation" %}

Form fields — what the operator is entering

  • Strain — Free-text mushroom strain identifier (e.g. P. cubensis). Carried into the doc header and the ledger.
  • Culture Lot # — Lab-assigned lot number for the inoculum. Carried into the doc header.
  • Container Type — Any container defined under containers: in config.yaml (e.g. monotub, 4liter_box, 2liter_box). Determines per-container substrate/spawn/LC masses. New containers are added via Settings → Configuration.
  • Avg Yield Fresh (g/container) — Expected fresh mushroom yield per container. Drives dry yield via the dry-matter ratio. Required for the standard calculation; in reverse mode it only feeds the expected-yield estimate.
  • Target Dry Weight (g) — Total dry mushroom you want to produce. Drives base container count. Required for the standard calculation; not used in reverse mode.
  • Spawn Bags Colonized + Spawn Bag Size (g) — Optional, both-or-neither. When filled, the calculator reverse-engineers the workplan from spawn already colonized: containers = floor(bags × size / spawn-per-container), substrate is calculated for exactly those containers, and grain-spawn prep / liquid culture are shown as not required. The contamination buffer and target dry weight do not apply in reverse mode.

Document sections — what is calculated and why

  • 1. CONTAINER PREP
    • Dry yield/container = fresh × 0.07 (7% dry matter ratio, configurable)
    • Base containers = target_dry_weight / dry_yield/container
    • Total containers = ceil(base × 1.10) — the 10% contamination buffer covers losses from contaminated jars, poor colonization, etc. This is why total > base.
  • 2. BULK SUBSTRATE PREP
    • Total substrate = total_containers × substrate_per_container
    • Buckets = ceil(total_substrate / 6300) — per-bucket recipe (SOP FORM-CULT-004) is 780g coir + 660g vermiculite + 60g gypsum + 4800ml water = 6300g net per bucket. The number of buckets is rounded up so you always have a little extra.
  • 3. GRAIN SPAWN PREP
    • Total spawn = total_containers × spawn_per_container
    • Grain batches = ceil(total_spawn / 10000) — each batch is 5000g grain + 10000ml water (SOP FORM-CULT-003: 5 kg : 10 L).
  • 4. INOCULATION & BAGGING
    • Bag count = total_containers (one bag per container)
    • LC per bag = configured per container type (e.g. 20ml for monotub)
{% elif kind == "extraction" %}

Form fields — what the operator is entering

  • Production Lot # — Identifier for the whole extract lot (one CP record may pool several EX records). Carried into the doc and the ledger. In V5.0 this is also the lot number recorded in the master log: the separate “Dry Mushroom Powder Lot #” field has been removed.
  • Strain — Same as cultivation.
  • Solvent Concentration — 100% / 90% / 75% MeOH, from allowed_solvent_types in config.yaml. Sets the per-bottle water addition and MeOH removal.
  • Total Dried Mushroom Powder (g) — Total weight of the production lot. The plan splits it into whole 120 g portions; a partial portion is never extracted.
  • Bottles per Extraction Day — How many bottles are loaded on each extraction day. Default 2. The last round may be partial (fewer bottles) when the lot does not divide evenly.
  • Portion per Bottle (g) — GMP-fixed at 120 g by extraction_parameters.grams_per_bottle. Shown read-only in the form; it is not an operator input in V5.0.
  • Grinder Loss Budget (g/round) — Mass expected to be lost during grinding. Defaults to 10g per round. Reported as a budget; it is not subtracted from the portions.
  • Yield Override (optional) — Supervisor-supplied concentration factor (e.g. 1:5 instead of default 1:4). Use this when historical data shows the actual concentration is different from the config default.

Document sections — what is calculated and why

  • 1. Lot summary
    • Total bottles = floor(total powder / 120 g) — only whole portions are extracted.
    • Powder processed = total bottles × 120 g. Leftover = total powder − powder processed; it is documented and held, never extracted (GMP: no partial-bottle extraction).
    • Extraction days = ceil(total bottles / bottles per day). Total procedure days = extraction days × 2 (one extraction day + one rotary-evaporation day per round).
  • 2. Solvent preparation (per bottle)
    • The bench stock is a 2.5 L bottle of 100% MeOH. The 2.4 L working volume is prepared from it by taking MeOH out and putting water back in:
    • MeOH to take out = 2500 − (2400 × %/100)
    • water to put back = 2400 × (1 − %/100)
    • At 90% MeOH: take out 340 mL, put back 240 mL → 2400 mL at 90%. At 75%: take out 700, put back 600. At 100%: take out 100, put back 0.
    • One extraction bottle is charged with 120 g of dried mushroom + 2400 mL of that working volume — a mushroom : solvent ratio of 1:20.
  • 3. Bottles & reagent totals
    • Total MeOH to remove = per-bottle value × total bottles. Total water to add = per-bottle value × total bottles.
    • Stock bottles required = ceil(total solvent charged / 2500 mL) — how many 2.5 L MeOH stock bottles to have on the bench.
    • Expected total extract = total powder processed / yield factor. At the default 1:4, 360 g processed → 90 g extract (25% yield).
  • 4. Timeline
    • One row per calendar day. Extraction rows carry the bottle count, the grams loaded and the solvent volumes; evaporation rows carry no materials.
    • Expected extract per extraction row = grams loaded that day / yield factor.
{% elif kind == "capsulation" %}

Form fields — what the operator is entering

  • Production Lot # — Identifier for the production lot being capsulated. Carried into the doc and the ledger.
  • Source EX Doc Numbers — Comma-separated list of EX records whose extract is pooled into this lot. Required — cross-tab traceability under GMP.
  • Total Extract (g) — Pooled dry extract mass (sum of all upstream EX record outputs).
  • Dosage Mode — Psilocybin only (psilocybin% alone) or Total Psilocybin Equivalents (TPE) (combined potency).
  • Psilocybin / Psilocin (%) — Lab-measured active-ingredient content of the extract, expressed as percent of dry extract mass.
  • Anti-Caking Agent (% of blend) — Default 5%. Applied to blend mass, not extract mass (pharmaceutical excipient convention).
  • Anti-Caking Agent Name — Free text, e.g. fumed silica, MCC, starch.

Document sections — what is calculated and why

  • Active-ingredient calculation
    • Psilocybin mass = extract × psilocybin% / 100
    • Psilocin mass = extract × psilocin% / 100
    • TPE% = psilocybin% + (psilocin% × 1.39)
      The 1.39 multiplier = MWpsilocybin / MWpsilocin = 284.25 / 204.27. It expresses psilocin content in psilocybin-equivalent potency.
    • Active mass used = psilocybin mass (mode 1) or TPE mass (mode 2).
  • Blend composition
    • Anti-caking: 5% of blend means anti_caking = extract × 5 / 95. At 100g extract + 5% blend anti-caking: anti_caking = 5.26g, blend = 105.26g.
    • mg active per g blend = active_mg / blend_g. Used to back-calculate blend mass per capsule.
  • Capsule specifications
    • Blend per capsule (mg) = dose_mg / (mg_active_per_g_blend / 1000) — tells the operator how many mg of blend to load into each capsule shell.
    • Max capsules from lot = floor(blend_g × 1000 / blend_per_capsule_mg) — the maximum count of each capsule type if 100% of the lot went to that type. Operator decides the actual mix.
  • Lot distribution plan — blank rows for the operator to write the planned/actual capsule counts per type at the bench.
