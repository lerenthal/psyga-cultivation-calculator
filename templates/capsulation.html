Capsulation Production Record

HOW TO USE THIS TAB

  • Mandatory: Production Lot #, Source EX Doc Numbers (comma-separated, at least one), Total Extract (g), Dosage Calculation Mode (dropdown — all options come from config.yaml), Psilocybin % and Psilocin % of the extract.
  • Optional: Anti-Caking Agent (% of blend, default 5%) and Anti-Caking Agent Name (e.g. fumed silica, MCC).
  • Expected output: a printable Capsulation Production Record (CP doc number) cross-referencing the upstream EX records, with the active-ingredient calculation (incl. TPE), blend composition, and a capsule-specification table (per capsule type: target dose, blend mass per capsule, maximum capsules from the lot), plus Operator / QA / Date signature lines.

Calculates blend composition, capsule-fill masses, and maximum capsule counts from a pooled dry-extract lot. Cross-references the upstream extraction records (EX doc numbers) for traceability.

Comma-separated list of EX records whose extract is pooled into this lot. Required.
Pooled dry extract mass from all upstream extraction rounds.
TPE = psilocybin + (psilocin × 1.39) for potency equivalence.
Default 5%. Applied to BLEND mass per pharmaceutical excipient convention.
