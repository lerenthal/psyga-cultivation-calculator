Cultivation Calculator (Working Protocol)

HOW TO USE THIS TAB

  • Mandatory (standard calculation): Strain, Culture Lot #, Container Type (dropdown — all options come from config.yaml), Avg Yield Fresh (g/container), Target Dry Weight (g).
  • Optional (reverse calculation): Spawn Bags Colonized and Spawn Bag Size (g) — fill both to reverse-calculate substrate from spawn you have already colonized. Leave both blank for the standard calculation. In reverse mode the Target Dry Weight is not used and Avg Yield only feeds the expected-yield estimate.
  • Expected output: a printable Facility Working Protocol (WP doc number) with container count, substrate buckets + ingredient totals, grain-spawn batches, inoculation/bagging amounts (or “Not required” in reverse mode), and Technician / QA / Date signature lines — followed by the printable raw-material SOP forms (spawn FORM-CULT-003, substrate FORM-CULT-004, media FORM-CULT-009) pre-filled with these amounts.
Need a different container (e.g. a 2liter shoebox)? Add it under containers: in config.yaml — admins can do this in Settings → Configuration without touching the server (no code change, no restart; it appears here on the next page load). Technicians: ask an admin to add it for you.
