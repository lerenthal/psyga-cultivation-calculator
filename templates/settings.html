Settings

Admin-only page. Edit calculation options in config.yaml below (no server access or restart needed — changes take effect on the next page load), and manage user accounts. Every saved config change is backed up and recorded in the history at the bottom.

Configuration (config.yaml)

Edit the whole file, then Save Config. The new text is checked before anything is written: invalid YAML or an invalid value (for example a container missing substrate, spawn or liquid_culture) is rejected with a message naming the exact key, and the current file is left untouched. On a successful save the previous file is backed up to config_backups/ and the change is recorded below.
